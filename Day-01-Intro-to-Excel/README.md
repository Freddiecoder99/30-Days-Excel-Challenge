## What I Learned

### Workbook

A workbook is the Excel file itself.

For example:

`monthly_sales.xlsx`

A workbook can contain multiple worksheets.

### Worksheet

A worksheet is an individual tab inside an Excel workbook.

For example, one workbook could contain worksheets called:

* Raw Data
* Analysis
* Charts
* Summary

### Rows and Columns

Rows run horizontally across the worksheet and are identified using numbers.

Examples:

* Row 1
* Row 2
* Row 3

Columns run vertically and are identified using letters.

Examples:

* Column A
* Column B
* Column C

### Cells

A cell is where a row and column intersect.

For example:

`B4`

means Column B, Row 4.

### Cell Ranges

A range is a group of cells.

For example:

`A1:D10`

means all the cells between A1 and D10.

## Why This Matters for Data Analysis

Before analyzing data, I need to understand how Excel stores and organizes information.

Most Excel analysis begins with data arranged in rows and columns, so understanding cells, ranges, worksheets, and workbooks is fundamental.

## Key Takeaways

1. A workbook is the complete Excel file.
2. A worksheet is one tab inside a workbook.
3. Every cell has an address based on its column and row.
4. Data should be organized clearly before attempting analysis.
5. Saving and organizing files properly is part of working with data.

## Reflection

My biggest takeaway from Day 1 is that Excel is more than a calculator. It provides a structured environment where data can be stored, organized, calculated, analyzed, and eventually visualized.

This lesson was basic, but understanding the interface properly will make the later lessons easier.
