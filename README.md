# 30 Days Excel Challenge

A practical 30-day Excel journey focused on strengthening my skills in data analysis, data preparation, modelling, automation, and dashboard development.

This repository brings together my daily learning notes, hands-on exercises, analytical projects, and the final capstone project from the **30 Day Excel Challenge by SDW Online**.

Rather than treating Excel as a collection of disconnected features, I approached the challenge as a progression toward a complete analytical workflow:

**Understand → Prepare → Analyse → Model → Visualise → Automate → Communicate**

By the end of the challenge, I worked from core Excel functionality through Power Query, Power Pivot, DAX, data quality auditing, macros, data-entry forms, and dashboard development.

## What I Worked On

Across the 30 days, my focus expanded from spreadsheet fundamentals into increasingly analytical and automated workflows.

### Excel Foundations

The early part of the challenge strengthened my ability to work confidently with Excel as an analytical environment.

I worked with:

* Workbooks and worksheets
* Data entry and organization
* Tables
* Number and date formatting
* Relative and absolute references
* Basic formulas
* `SUM`
* `AVERAGE`
* `MAX`
* `MIN`
* `COUNT`
* Sorting and filtering

These fundamentals became the building blocks for the more advanced work later in the challenge.

### Analytical Functions

I developed my ability to use formulas to transform, categorize, retrieve, and summarize information.

Topics included:

* Logical functions
* `IF` and conditional logic
* Text functions
* Aggregate functions
* `VLOOKUP`
* `HLOOKUP`
* `INDEX`
* `MATCH`
* `XLOOKUP`
* Dynamic array functions

This gave me multiple approaches for solving data retrieval and transformation problems depending on the structure of the dataset.

### Data Cleaning and Quality

A significant part of the challenge focused on making data reliable before using it for analysis.

I worked with:

* Missing values
* Duplicate records
* Invalid values
* Data validation
* Reference lists
* Dropdowns
* Outlier checks
* Data quality summaries
* Conditional formatting for quality checks

One of the important lessons from this part of the challenge was that analysis does not start with a chart. It starts with understanding whether the data can be trusted.

### PivotTables and Data Summarisation

I used PivotTables to turn larger datasets into meaningful summaries.

This included:

* Grouping and summarising data
* Calculating totals and averages
* Comparing categories
* Exploring trends
* Building reports from structured datasets
* Using PivotTables as the foundation for visual analysis

The emphasis was on using PivotTables to answer questions rather than simply creating summaries for their own sake.

### Power Query

Power Query became a major part of the later stages of the challenge.

I worked with data imported from:

* Excel
* CSV files
* Multiple CSV files in folders
* Websites
* SQL databases
* PDF documents

I also practiced:

* Data transformation
* Combining files
* Custom columns
* IF-ELSE logic
* Merging columns
* Inner joins
* Left joins
* Right joins
* Outer joins

This strengthened my understanding of how data can be prepared and integrated before analysis.

### Power Pivot and Data Modelling

I also moved beyond single-table analysis into data modelling with Power Pivot.

Topics included:

* Loading tables into the data model
* Creating table relationships
* One-to-one relationships
* One-to-many relationships
* Many-to-many relationships
* Bridge tables
* Fact tables
* Dimension tables
* Diagram View
* PivotTables built from the data model

This introduced a more structured way of thinking about how different datasets relate to each other.

### DAX

I worked with DAX as part of the Power Pivot data model.

I practiced creating:

* DAX measures
* `COUNTROWS`
* Click-count measures
* Average-time calculations
* Sentiment measures
* Design-related measures
* User behaviour measures
* Calculated columns
* Feature click counts
* Low-usage flags

The focus was on using DAX to turn relationships and raw data into dynamic analytical metrics.

### Data Visualization

I strengthened my ability to select and build visuals that communicate different types of information.

Charts covered throughout the challenge included:

* Column charts
* Bar charts
* Line charts
* Pie charts
* Donut charts
* Clustered bar charts
* Heat maps

The later projects placed more emphasis on connecting each visual to a specific analytical question.

### Macros and Automation

I explored Excel automation using recorded macros and VBA.

This included:

* Enabling the Developer tab
* Recording macros
* Formatting data automatically
* Automating data quality reports
* Testing macros on new datasets
* Creating dashboards with macros
* Creating charts through automation
* Fixing chart positioning with VBA
* Building a master macro
* Assigning macros to buttons
* Creating a one-click dashboard workflow

This demonstrated how Excel can be used not just for analysis, but also for repeatable reporting processes.

### Data-Entry Forms

I also built a structured data-entry system around an IT equipment request scenario.

The project included:

* Structured data tables
* Reference lists
* Dropdown menus
* Data validation
* Quantity limits
* Conditional formatting
* Status indicators
* Request logs
* Submit macros
* Clear form macros
* Clear log macros
* Buttons
* End-to-end testing

This connected data collection with data quality, showing how cleaner data can be encouraged before it reaches the analysis stage.

## Final Takeaway

Completing the 30 Day Excel Challenge strengthened the way I approach data in Excel.

I moved through the challenge from individual formulas and spreadsheet techniques into data cleaning, structured analysis, data modelling, automation, and dashboard development.

More importantly, I became more deliberate about the sequence behind good analysis:

**Start with the question.
Understand the data.
Check the quality.
Prepare the data.
Build the model.
Analyse it.
Visualise the answer.
Communicate what matters.**

That is the mindset I am carrying forward as I continue developing my broader data analysis skill set.
