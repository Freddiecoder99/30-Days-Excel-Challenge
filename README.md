# 30 Days Excel Challenge

This repository documents my 30-day journey learning Microsoft Excel for data analysis.

I am using this challenge to build a strong foundation in Excel while developing the habit of applying what I learn through practical exercises and independent projects.

## My Learning Approach

My approach throughout this challenge is:

**Learn → Practice → Apply → Document**

During each learning day, I study an Excel concept, practice it using exercises, and document what I learned.

At the end of each week, I complete an independent project that combines the skills I learned during that week.

The goal is to understand not only how Excel features work, but also how they can be used to analyze real data.
