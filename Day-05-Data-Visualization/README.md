# Day 5: Data Visualization Part 1

## Overview

Today I learned how Excel charts can be used to communicate patterns in data.

I learned that choosing the correct chart is more important than simply creating something visually attractive.

## What I Learned

### Column Charts

Column charts are useful for comparing values between categories.

For example:

* Sales by region
* Population by country
* Revenue by product

### Bar Charts

Bar charts are also useful for comparing categories.

They are particularly useful when category names are long because the labels are easier to read.

### Line Charts

Line charts are useful for displaying how something changes over time.

For example:

* Monthly revenue
* Annual population
* Daily website traffic

### Pie Charts

Pie charts show how individual categories contribute to a whole.

They are most useful when there are only a small number of categories.

Too many slices make a pie chart difficult to understand.

### Chart Titles

A chart title should explain what the visualization shows.

For example:

Instead of:

`Chart 1`

I should use:

`Monthly Sales Revenue - 2026`

### Labels and Axes

I practiced formatting:

* Chart titles
* Axis titles
* Data labels
* Legends

These elements provide context for the viewer.

## Choosing the Right Chart

I learned to think about the question first.

If I want to compare categories:

* Column chart
* Bar chart

If I want to show change over time:

* Line chart

If I want to show simple parts of a whole:

* Pie chart

## Why This Matters for Data Analysis

A table may contain the correct numbers, but a chart can make a pattern much easier to recognize.

Charts help communicate findings to people who may not want to inspect every row of a dataset.

## Practice

Today I practiced:

* Creating column charts
* Creating bar charts
* Creating line charts
* Creating pie charts
* Adding chart titles
* Formatting labels
* Formatting axes
* Improving chart readability

## Key Takeaways

1. A visualization should answer a question.
2. Different charts are suited to different kinds of information.
3. Line charts are useful for trends over time.
4. Bar and column charts are useful for comparisons.
5. Pie charts should be used carefully.
6. A chart should make the data easier to understand.

## Reflection

The biggest lesson from today was that data visualization is not decoration.

A good chart should make an insight easier to see.

I also learned that adding more visual effects does not automatically make a chart better.
