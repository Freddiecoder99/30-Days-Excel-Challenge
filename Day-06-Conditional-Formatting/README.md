# Day 6: Conditional Formatting Part 1

## Overview

Today I learned how Excel can automatically apply formatting based on the values stored in cells.

This makes it easier to identify patterns, unusually high or low values, and other information that deserves attention.

## What I Learned

### Highlight Cell Rules

Excel can highlight cells that meet specific conditions.

Examples include:

* Greater Than
* Less Than
* Equal To
* Between
* Duplicate Values

### Data Bars

Data bars create visual bars inside cells.

Larger values display longer bars.

This makes it possible to compare values visually without creating a separate chart.

### Color Scales

Color scales use different shades or colors to represent differences between values.

They can help identify:

* High values
* Middle values
* Low values

### Icon Sets

Icon sets can provide visual indicators such as:

* Up arrows
* Down arrows
* Traffic lights
* Ratings

These can make status and performance easier to understand.

## Why This Matters for Data Analysis

Conditional formatting helps an analyst quickly identify:

* High-performing values
* Low-performing values
* Outliers
* Duplicates
* Trends
* Values requiring attention

It provides a visual layer on top of the numeric data.

## Important Lesson

Conditional formatting should have a purpose.

Adding many different colors simply because Excel allows it can make a worksheet harder to understand.

The formatting should help answer a question or draw attention to something important.

## Practice

Today I practiced:

* Highlight Cell Rules
* Data Bars
* Color Scales
* Icon Sets
* Removing conditional formatting
* Applying formatting based on numeric values

## Key Takeaways

1. Conditional formatting reacts to cell values.
2. Data bars help compare numeric values quickly.
3. Color scales help identify high and low values.
4. Icon sets can communicate status.
5. Conditional formatting should improve understanding rather than create visual clutter.

## Reflection

Today I learned that Excel can make patterns visible without changing the data itself.

I particularly liked data bars because they make a normal numeric column feel almost like a chart while still keeping the exact values visible.
