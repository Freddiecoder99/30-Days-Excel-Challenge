# Day 4: Sorting and Filtering Data

## Overview

Today I learned how to explore a dataset without changing the actual values inside it.

Sorting helps organize rows into a useful order, while filtering allows me to temporarily display only the records that meet certain conditions.

## What I Learned

### Sorting

Sorting changes the order of rows.

For text, I can sort:

* A to Z
* Z to A

For numbers:

* Smallest to Largest
* Largest to Smallest

For dates:

* Oldest to Newest
* Newest to Oldest

### Multi-Level Sorting

Sometimes one sorting condition is not enough.

For example, I could first sort employees by department and then sort their salaries from largest to smallest within each department.

This is called multi-level sorting.

### Filtering

Filtering temporarily hides records that do not meet a condition.

For example:

`Region = East`

would display only records belonging to the East region.

The hidden rows are not deleted.

### Number Filters

Numeric columns can be filtered using conditions such as:

* Greater Than
* Less Than
* Equal To
* Between
* Top 10

### Text Filters

Text can be filtered using conditions such as:

* Equals
* Does Not Equal
* Begins With
* Contains

### Filtering by Color or Icons

When formatting has been applied to data, Excel can also filter based on:

* Cell color
* Font color
* Conditional formatting icons

## Sort vs Filter

The main distinction I learned is:

**Sorting changes the order of the data.**

**Filtering changes which records are currently visible.**

## Why This Matters for Data Analysis

Sorting and filtering allow me to quickly investigate questions such as:

* Which values are the highest?
* Which values are the lowest?
* Which records belong to one category?
* Which transactions exceed a certain amount?
* Which rows match a particular condition?

These techniques are useful when exploring data before performing more advanced analysis.

## Key Takeaways

1. Sorting reorganizes records.
2. Filtering temporarily hides records.
3. Filtering does not delete information.
4. Multiple filters can narrow a dataset.
5. Sorting and filtering are useful tools for exploring data.

## Reflection

The main lesson for me today was that I do not always need a formula to investigate data.

Sometimes simply sorting from largest to smallest or filtering one category can immediately answer a question.
